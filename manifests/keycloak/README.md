# Keycloak

Identity provider setup deployed to `keycloak-system` namespace.

## Resources

- `keycloak-instance.yaml` - Keycloak CR (operator-managed instance)
- `realms-configmap.yaml` - Pre-configured realms for each tenant
- `http-route.yaml` - HTTPRoute for external access via gateway

## Configuration

`params.env` is generated by `scripts/obtain-cluster-config.sh` with the keycloak hostname.

Note: The Keycloak Gateway lives in `gateways/` (must be in `openshift-ingress` namespace).
