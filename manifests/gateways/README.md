# Gateways

Kubernetes Gateway API resources deployed to `openshift-ingress` namespace.

## Resources

- `gateway-class.yaml` - GatewayClass for OpenShift
- `keycloak-gateway.yaml` - Gateway for Keycloak identity provider
- `tenant-a-gateway.yaml` - Gateway for tenant-a model endpoints
- `tenant-b-gateway.yaml` - Gateway for tenant-b model endpoints

## Configuration

`params.env` is generated by `scripts/obtain-cluster-config.sh` and contains:
- TLS secret name
- Hostnames for keycloak and each tenant

Kustomize replacements inject these values into Gateway specs.
